# 校园淘淘：二手商品智能助手

这是一个用于机器学习课程展示的校园二手交易平台原型。项目将公开的 Mercari 二手商品数据、文本价格预测模型和 Streamlit 网页应用结合起来，提供商品浏览、相似商品搜索、智能估价、商品发布和模拟交易等功能。

## 一、快速运行

建议使用 Python 3.10 或更高版本。解压后，在 PowerShell 中进入项目目录：

```powershell
cd 校园淘淘
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.port 8517
```

浏览器打开：`http://localhost:8517`

Windows 用户也可以直接双击 `启动应用.bat`。如果 8517 端口被占用，可以改用：

```powershell
python -m streamlit run app.py --server.port 8518
```

项目已包含训练好的模型，直接启动不需要重新训练。

## 三、推荐展示流程

1. 在“商品浏览”中搜索“蓝牙耳机”。
2. 点击商品卡片，进入商品详情。
3. 点击“使用当前商品信息估价”。
4. 展示参考价格、合理价格区间和价格雷达。
5. 修改成色或运费，展示交互实验结果变化。
6. 在商品详情点击“查找与这件商品相似的商品”，比较候选商品的文本相似度和价格差。
7. 也可以打开“相似商品”，选择“游戏手柄”作参照，再点击候选商品的“查看详情”。
8. 打开“模型表现”，展示类别中位价、随机森林、XGBoost 与岭回归的同测试集对比。
9. 如有时间，登录后进入“发布商品”，发布一件商品，再从“账号与记录”进入详情并估价。

## 四、机器学习方法

### 1. 智能估价

价格模型使用商品名称、商品描述、商品大类、小类、细分类、品牌、成色和运费等信息。

- 商品名称和描述：使用 TF-IDF 转换为文本特征；
- 类别和品牌：使用独热编码；
- 成色和运费：作为数值特征并标准化；
- 预测模型：岭回归；
- 预测目标：`log(人民币价格 + 1)`，预测后再还原为人民币价格。

训练过程使用训练集、验证集和测试集，并在训练集内部选择岭回归正则化强度。当前模型使用 `alpha=3.0`。

### 2. 模型对比实验

“模型表现”页读取 `model_comparison.json`，展示同一 8 万条训练记录、2 万条测试记录上的离线结果。三个学习模型使用相同的 TF-IDF、独热编码和数值特征，以人民币价格计算平均绝对误差、均方根误差和 R²。当前实验中岭回归误差最低；随机森林与 XGBoost 使用固定演示参数，结果不代表它们经过充分调参后的最佳表现。网站在线估价仍使用岭回归。

压缩包已附实验结果，启动网页不需要安装 XGBoost。要自己重新运行对比实验，先安装额外依赖，再执行脚本：

```powershell
python -m pip install -r requirements-comparison.txt
python compare_price_models.py
```

### 3. 同类商品推荐

商品浏览中的关键词搜索用于查找商品；“相似商品”以一条已有商品为参照，优先在同一细分类（样本不足时逐级扩大到小类或大类）中寻找可比较的商品，并排除参照商品本身。标题与描述用 TF-IDF 转换为文本向量，再计算余弦相似度；标题占 75%，标题加描述占 25%。结果展示文本相似度和相对参照商品的记录价格差。商品详情页也可直接发起推荐。

这属于基于内容的商品推荐，不是同款识别；图片只作类别示例，不参与相似度计算。

### 4. 其他功能

- 价格范围：根据验证集预测残差进行区间校准；
- 校园适配度：根据类别和关键词进行规则评分；
- 商品图片：使用按类别整理的示例图，主要用于页面展示；
- 登录和交易：使用本地 SQLite 数据库保存演示记录。

## 五、数据和图片说明

项目使用公开的 Mercari 二手商品数据。原始价格为美元，项目按参考汇率转换成人民币。数据来自美国二手交易平台，不代表校园真实成交价格。

页面中的图片来自 Amazon Berkeley Objects 商品目录，经过校园类别筛选和整理。图片是类别示例图，不一定对应某条 Mercari 商品记录，也不代表商品实际成色。使用或公开展示时请保留数据集来源和署名信息。

## 七、重新训练模型

当前压缩包已经包含训练好的模型，直接启动不需要训练。如果修改了数据或希望重新训练，可以运行：

```powershell
python train_model.py
```

也可以双击 `重新训练模型.bat`。训练脚本会读取 `data/data.parquet`，转换人民币价格，重新训练模型并更新 `models/price_model.joblib` 和 `metrics.json`。

## 八、常见问题

### 找不到 `app.py`

请先进入包含 `app.py` 的项目目录，再运行 Streamlit：

```powershell
cd 项目目录
python -m streamlit run app.py --server.port 8517
```

### 页面提示缺少模型

确认 `models/price_model.joblib` 存在。若不存在，先运行 `python train_model.py`。

### 页面没有图片

确认 `showcase_校园筛选_官方类型` 文件夹和其中的 `metadata_labels.csv` 存在。图片只是展示素材，不影响价格模型运行。

### 中文描述是否被模型完整理解

原始训练数据主要是英文。页面对常见中文关键词做了本地映射，复杂中文描述的文本特征利用有限；类别、品牌、成色和运费仍会参与预测。演示时应将模型称为英文公开数据上的价格参考模型。

## 九、项目限制

- 数据来自美国平台，不是校园本地交易数据；
- 图片没有参与价格预测和相似商品匹配；
- 价格预测结果是参考值，不是交易承诺；
- 相似商品是文本相似，不代表同款；
- 登录、购买和交易记录是本地演示功能，不连接真实支付系统。
